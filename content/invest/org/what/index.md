知己知彼，百战不殆。在股票市场，你需要知道，大头资金其实是机构和量化，所以你要想赚钱的话，你应该去赚机构的钱，然后机构去赚散户的钱，这是一个廉价七成的逻辑链条。

所以很重要的一点就是研究那些基金经理，因为 **个人的行为总是比整体更好预测**，你需要去了解：那些人的阶级出生是什么？他们每天的工作流程是什么？他们的优势和劣势在哪里？在此情况下你的赢面在哪里？

### 机构的优势

机构有三大优势：信息获取能力、价值建模能力、资金和博弈能力。

#### 信息获取能力

* 券商卖方天天跑产业链（调研、电话会、草根调研）
* 能直接对接上游（封装厂、设备厂、材料厂）
* 有渠道拿到：
  * 订单变化（比如 CoWoS 产能利用率）
  * 价格趋势（HBM报价、ABF载板涨价）
  * 客户结构（是不是进了 NVIDIA / AMD 供应链）

#### 建模能力

他们会做这种东西：

* 行业空间（TAM）
* 单位利润拆解
* 渗透率假设
* 三表预测（3-5年）

#### 资金与博弈能力

* 能提前潜伏
* 能做趋势
* 能控节奏（抱团/出货）

所以我们可以总结一下这几个特点：

- 你看到新闻的时候，他们已经建完仓了
- 他们能根据当前所有能获取到的信息算出 **合理市值区间**
- A股很多龙头，本质是 **“机构共识产物”**

{{< region note >}}
**公理一**：普通人想用 "信息驱动投资" 战胜机构，可能性基本为 0，可以直接放弃这条路子。

很多股民每天热衷于当一个 “小道消息收藏家”，这里你要思考两个点：

1. 机构的信息比你更多更权威。
2. 你基于有限外部信息分析得到的结果大概率严重失真，机构结合各层面信息建模的结果更加客观。

这种情况下胜率不大，本着第一性原理，直接抛弃这种方案；此外，每天都接受各种信息轰炸，会给人的身心都带来非常负面的影响。

### 机构的工作流

大多数机构对于经济行为的论证方式是 **从结果解释原因**：先看到现象、然后去调研、最后写结论。

其实极少数顶尖研究员也有能力根据逻辑从原因推导结果，能做到这种的，已经是 “产业专家 + 半工程师” 了，但是这种行为一般不会被机构的工作机制所激励，因为：

1. **机构需要“可验证”的东西**

- 对于一个未验证的东西，机构如果写报告：
    - 客户会问：证据呢？
    - 投委会不会批
- 所以他们必须等数据出现以及公司确认

> 我们可以构建一个这样的思想实验：
>
> 2023 年某个机构研究员从大模型推理中的 decode 阶段的 memory bound 特性，预估到几年后的 hbm 会进一步增长。
>
> 2025 年某个机构研究员观察到未来 AI agent 场景会爆发，数据中心会增加对于内存
>
> 但是当时没有订单、数据、公司指引来明确验证这种思路，除了极少数私人投资公司外，机构不会有魄力来进行这种投资。

2. **他们承担“职业风险”**

大多数机构不敢承担风险，因为亏钱以后他们要承担巨大的代价。

这个特性决定了机构天然是 **右侧玩家**（确定后再跟上）。

### 散户的赢点

散户要想跑赢机构，首先应该

1. 你有一个专门从事的行业
    - 首先你应该将自己的工作内容有深入理解
    - 对行业中上下游依赖关系能够建模
    - 不能做一个每天无所事事的 “知道分子”
2. 承担风险和不确定性的能力
